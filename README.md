# Pavan M — portfolio

A single-page portfolio site. No build step, no dependencies, no framework.
Three files and an image folder.

```
portfolio/
├── index.html
├── styles.css
├── main.js
├── README.md
└── assets/
    └── img/        ← put your renders here
```

## Preview it

Double-click `index.html`. That's the whole thing.

If you want a local server (closer to how it behaves when deployed):

```powershell
cd C:\Workspace\portfolio
npx serve .
```

## Add your work

Open `main.js`. The first ~60 lines are the only part you need to touch.

```js
{
  title: "Kettle Study",
  category: "Product",        // Product | Character | Environment | Motion
  year: "2026",
  tags: ["Hard-surface", "Cycles", "PBR"],
  size: "wide",               // wide | half | full
  image: "",                  // ← put your file path here
  tone: ["#2b303c", "#5c4033"],
}
```

To add an image:

1. Save the render into `assets/img/` — e.g. `assets/img/kettle.jpg`
2. Set `image: "assets/img/kettle.jpg"`
3. Keep images under ~2000px on the long edge and save as JPG or WebP. Export at quality 80–85; a portfolio doesn't need 8MB PNGs.

When `image` is empty, the card shows a generated viewport-style placeholder with a small **PLACEHOLDER** tag. Set an image and the tag disappears automatically.

**Before you publish:** rename all six projects, change the years and tags, and replace the placeholder copy in `index.html` (hero, about, services). The current text is written to be plausible, not true.

## Change the look

All colours and type live at the top of `styles.css` under `:root`.

- `--accent` is the terracotta used for the italic word and hover states. Try `#7ea6d9` for a cooler palette.
- `--bone` is the off-white text colour.
- `--ink` is the background.

## Deploy (free)

**Netlify** — go to app.netlify.com/drop and drag the `portfolio` folder onto the page. You get a live URL in about ten seconds. Rename it in Site settings.

**GitHub Pages**

```powershell
cd C:\Workspace\portfolio
git init
git add .
git commit -m "portfolio"
gh repo create portfolio --public --source=. --push
```

Then in the repo: Settings → Pages → Source: `main` / root. Live at
`https://<your-username>.github.io/portfolio/`.

**Vercel** — `npx vercel` inside the folder, accept the defaults.

Either way, add the link to your Fiverr profile and your LinkedIn.

## Notes

- Works without JavaScript except the project grid and filters, which are generated by `main.js`.
- Respects `prefers-reduced-motion`, has visible focus states, keyboard-navigable lightbox (`←` `→`, `Esc`).
- The lightbox uses `<dialog>`, so it traps focus and closes on backdrop click for free.
- Fonts load from Google Fonts with system fallbacks. To go fully offline, delete the three `<link>` tags in `index.html` and the page will fall back to Georgia and Segoe UI.
